# Руководство пользователя для RESTful API

## Введение
Это руководство предназначено для взаимодействия с RESTful API, разработанным на основе Laravel 10. API предоставляет функционал управления пользователями и их попытками. Версия API: `v1`.

## Структура API
API содержит следующие ресурсы:

1. **User**
2. **Attempt**

### Базовый URL
`/api/v1`

---

## Ресурс: User
### Эндпоинты

#### 1. Получение списка пользователей
**GET** `/user`

**Параметры запроса:**
- `limit` (int, необязательный): Ограничение на количество возвращаемых пользователей. По умолчанию: 10.
- `date` (string, необязательный): Фильтр по дате обновления (формат: `dmy`, например, `221124`).

**Пример ответа:**
```json
{
  "ok": true,
  "data": [
    {
      "id": 1,
      "name": "Иван Иванов",
      "score": 9,
      "updated_at": "2024-11-23"
    }
  ]
}
```

---

#### 2. Создание пользователя
**POST** `/user`

**Тело запроса (JSON):**
- `vk_id` (int, обязательный): ID пользователя VK.
- `name` (string, обязательный): Имя пользователя.
- `score` (int, обязательный): Рейтинг пользователя (от 1 до 10).
- `app` (string, обязательный): Название приложения.
- `reasons` (JSON, обязательный): Причины добавления.

**Пример запроса:**
```json
{
  "vk_id": 12345,
  "name": "Анна Смирнова",
  "score": 8,
  "app": "Приложение А",
  "reasons": "{\"reason1\": \"example\"}"
}
```

**Пример ответа:**
```json
{
  "ok": true,
  "data": {
    "id": 1,
    "name": "Анна Смирнова",
    "score": 8,
    "app_id": 3,
    "active": true
  }
}
```

---

#### 3. Получение информации о пользователе
**GET** `/user/{vk_id}`

**Пример ответа:**
```json
{
  "ok": true,
  "data": {
    "id": 1,
    "name": "Иван Иванов",
    "score": 9,
    "attempts_count": 3
  }
}
```

---

#### 4. Деактивация пользователя
**DELETE** `/user/{vk_id}`

**Пример ответа:**
```json
{
  "ok": true,
  "message": "Пользователь деактивирован.",
  "data": {
    "id": 1,
    "active": false
  }
}
```

---

## Ресурс: Attempt
### Эндпоинты

#### 1. Создание попытки
**POST** `/attempt`

**Тело запроса (JSON):**
- `vk_id` (int, обязательный): ID пользователя VK.

**Пример запроса:**
```json
{
  "vk_id": 12345
}
```

**Пример ответа:**
```json
{
  "ok": true,
  "data": {
    "attempts_count": 4
  }
}
```

---

#### 2. Получение количества попыток за текущий день
**GET** `/attempt/{vk_id}`

**Пример ответа:**
```json
{
  "ok": true,
  "data": {
    "attempts_count": 5
  }
}
```

---

## Общая структура ответа API
Все ответы API имеют следующую структуру:
```json
{
  "ok": true|false,
  "data": { ... },
  "error": "Описание ошибки" // если ok: false
}
```

---

## Возможные ошибки
### Общие ошибки
- **400**: Неверный запрос (например, некорректные параметры).
- **404**: Ресурс не найден.
- **500**: Ошибка сервера.

**Пример:**
```json
{
  "ok": false,
  "error": "Пользователь не найден."
}
```

---

## Примечания
1. Все запросы должны быть выполнены с использованием Content-Type: application/json.
2. Формат даты для фильтров: `dmy` (день, месяц, год).
